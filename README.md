# Zuri — état des services (miroir)

Miroir public de la page d'état de **Zuri secrétaire** et **Zuri assistante**,
hébergé hors de l'infrastructure qu'il décrit.

Une page de statut servie par la machine qu'elle surveille se tait le jour où
elle sert. Celle-ci lit l'état **en direct** sur la plateforme ; si la
plateforme est muette, elle affiche le dernier instantané déposé ici, en le
disant clairement au lecteur.

**Aucune donnée de santé, aucun nom de patient, aucun nom de cabinet** ne figure
dans ce dépôt : il ne porte que des voyants.

Page servie par la plateforme : https://zuri.soiagent.ai/statut/
